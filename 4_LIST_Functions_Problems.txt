1️⃣ append()
Problem 1

Add 50 to the list.

lst = [10, 20, 30, 40]


lst.append(50)
print(lst)


Output:

[10, 20, 30, 40, 50]

Problem 2

Add "Python" to subjects list.

subjects = ["Math", "Science"]

subjects.append("Python")
print(subjects)


Output:

['Math', 'Science', 'Python']

Problem 3

Append a list as a single element.

lst = [1, 2]
lst.append([3, 4])
print(lst)


Output:[1, 2, [3, 4]]

2️⃣ extend()
Problem 1

Add multiple numbers.

lst = [1, 2]
lst.extend([3, 4])
print(lst)


Output:[1, 2, 3, 4]

Problem 2

Extend with string.

lst = [1, 2]
lst.extend("AB")
print(lst)


Output:[1, 2, 'A', 'B']

Problem 3

Combine two lists.

a = [10, 20]
b = [30, 40]


a.extend(b)
print(a)


Output:[10, 20, 30, 40]

3️⃣ insert()
Problem 1

Insert 15 at index 1.

lst = [10, 20, 30]

lst.insert(1, 15)

print(lst)


Output:[10, 15, 20, 30]

Problem 2

Insert at beginning.

lst = [2, 3]
lst.insert(0, 1)
print(lst)


Output:[1, 2, 3]

Problem 3

Insert at large index.

lst = [1, 2]
lst.insert(10, 3)
print(lst)


Output:[1, 2, 3]

4️⃣ remove()
Problem 1

Remove value 20.

lst = [10, 20, 30]
lst.remove(20)
print(lst)


Output:[10, 30]

Problem 2

Remove first occurrence.

lst = [1, 2, 2, 3]
lst.remove(2)
print(lst)


Output:[1, 2, 3]

Problem 3

Remove string.

lst = ["a", "b", "c"]
lst.remove("b")
print(lst)


Output:['a', 'c']

5️⃣ pop()
Problem 1

Pop last element.

lst = [10, 20, 30]
lst.pop()
print(lst)


Output:[10, 20]

Problem 2

Pop index 1.

lst = [10, 20, 30]
lst.pop(1)
print(lst)


Output:

[10, 30]

Problem 3

Store popped value.

lst = [5, 6, 7]
x = lst.pop()
print(x)
print(lst)


Output:7
[5, 6]
